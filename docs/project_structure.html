features_project — codebase structure

Research pipeline testing whether LLMs know, from prior knowledge alone, which respondent characteristics predict how someone answers a survey question — and whether that reasoning adapts across countries. Surveys: WVS, ESS waves 10–11, and the Afro/Arab/Asian/Latino barometers.

The framing: an AutoGluon “oracle” computes the ground-truth feature ranking from the microdata (the answer key); the LLM nominates features from prior knowledge alone (the student with no notes). Both feature sets — plus a random baseline matched to the same k — are scored with XGBoost cross-validation.
cost_of_imperfect = oracle_acc − model_acc  ·  value_over_random = model_acc − random_acc

Directory tree

Every tracked file, color-coded by role, with line counts for code. outputs/, paper/ and .env are gitignored and not shown as files.

/ — root: the 5-step pipeline engine11 files
  • Orchestration
  • run_grid.py879Main entry point. Loads the survey once, then runs all five steps for every (target × country) cell in parallel threads; writes grid summaries, results JSON and the run manifest. Key CLI: --survey --targets --countries --from-manifest --run-tag --stop-after --prompt-variant --embedding-model.
  • generate.py172OpenAI-compatible LLM client factory (make_generate_fn) + TokenUsageLog writing per-request usage to llm_usage__*.jsonl. Works with Nebius, Together, OpenRouter, local SGLang, …
  • output_layout.py151The filesystem contract: model-slug sanitizing, llm__<tag>/ cache prefixes, grid-summary and manifest paths.
  • The five pipeline steps
  • phase0b_oracle_autogluon.py902Step 1 · Oracle. AutoGluon permutation importance = ground-truth ranking. Feature-pool construction, conditional-leakage detection, missing-value standardization, quick/balanced/best runtime modes. Cached to oracle.csv; also runs standalone.
  • phase0b_pipeline.py172Step 2 · LLM select. System prompt + the two condition templates (unprompted / country-provided); batch runner; JSON feature-list parsing.
  • phase0b_mapping.py223Step 3 · Embed + map. SentenceTransformer (default all-MiniLM-L6-v2) embeds LLM labels and survey-variable question text; cosine top-k retrieval; thread-safe model cache.
  • phase0b_disambig.py170Step 4 · Disambiguate. A fixed small LLM (DISAMBIG_MODEL, default Nemotron-3-Nano-30B) picks the best variable from each embedding shortlist — held constant so main-LLM runs stay comparable.
  • phase0b_evaluation.py267Step 5 · Evaluate. XGBoost 5-fold CV comparing oracle top-k / model-selected / random-k (20 draws), all matched to the same k → cost_of_imperfect, value_over_random.
  • run_prelim_full_all_surveys.ps173PowerShell driver: full prelim grid across all six surveys, with GRID_WORKERS / REBUILD_MANIFEST knobs and logging.
  • Root docs
  • README.md172Authoritative doc: setup, the 5 steps, supported surveys, run-tag experiment tracking, outputs contract, oracle extension point.
  • framing_and_comparisons.md138Conceptual guide: the oracle-as-answer-key framing and how the four comparison metrics relate.

outputs/ · paper/ — generated, gitignorednot tracked
  • outputs/<target>_<country>/oracle.csv—Permutation importances, shared across all models. Any CSV with the documented columns dropped here replaces the AutoGluon oracle — the extension point.
